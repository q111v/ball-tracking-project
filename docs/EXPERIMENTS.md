# 可重复实验与本次实测

## 目的与边界

将“真实预训练检测链路”与“控制变量的跟踪逻辑”分开验证。真实检测使用含体育球的照片生成视频；独立跟踪测试直接注入确定性检测框，不将彩色圆的识别率当作 YOLO 成绩。课程论文最终应另外采集未参与训练的自然运动视频。

## 指标定义

真值和输出框均用原视频像素 xyxy 坐标，帧号从 0 开始。仅评估真值 JSON 中列出的帧。每帧使用 Hungarian 一对一匹配，先最大化 IoU≥0.5 的有效匹配数量，再最大化 IoU；重叠小于阈值不算匹配。

- TP：与可见真值匹配的系统输出框；FN：未匹配的可见真值；FP：未匹配的系统输出。完全不可见真值不计入召回率分母，遮挡期输出仍可能是 FP。
- 检测成功率定义为可见球实例的召回率 `TP/(TP+FN)`，同时报告精确率 `TP/(TP+FP)`。这是 `model.track` 最终输出的端到端指标，包含跟踪确认/过滤影响，不是独立 YOLO 检测器的 AP 或 mAP。
- ID switches：同一真值在两次有有效 ID 的匹配之间，预测 ID 改变的次数；包括间隔和跨遮挡的匹配，不假设间隔帧都被检测。阶段统计把切换记入新匹配所在阶段。
- 跟踪稳定性代理值 `1-ID_switches/N`，N 为有有效 ID 的 TP 次数；附报 `tracked_match_fraction=N/TP`。稳定性必须与召回率及跟踪覆盖率同时解读，否则漏检会掩盖问题。它不等于 IDF1、HOTA 或 MOTA。
- 遮挡恢复：遮挡前存在有效匹配、且后来重新可见的事件作为分母；重现后的第一次有效匹配是否与遮挡前最后一次匹配同 ID。重现后一直未匹配记失败，另列 `occlusion_events_without_rematch`。此定义允许延迟恢复，并不等于第一帧恢复率。若视频结束前未重现，不算可评价事件。
- `inference_fps`：总帧数 / `model.track` 调用总时间，包括检测、关联及首次初始化开销。
- `processing_fps`：总帧数 / 推理、数据转移、绘图和可选视频写入总时间；不包含读取、显示等待和 CSV 写入。屏幕 FPS 是该处理速率的运行估计值，当前帧写入开销在下一帧反映。
- `wall_fps`：包含读取、显示等待和逐帧日志的循环吞吐率；不含模型加载与最终统计。
- 分阶段 FPS：对该阶段的 `processing_s` 求和，以参与统计的帧数除以总时间；默认只从 FPS 排除前 5 帧预热，准确率仍评估全部标注帧。写入与不写入视频的结果不可直接比较。

分母为零时输出 JSON `null`，不能把未检测到目标的“零次 ID 切换”解释为跟踪优秀。

## 真值格式与人工标注

```json
{
  "frames": [
    {"frame": 0, "phase": "before", "objects": [
      {"id": 1, "bbox": [100, 80, 140, 120], "visible": true}
    ]},
    {"frame": 1, "phase": "occluded", "objects": [
      {"id": 1, "bbox": [102, 80, 142, 120], "visible": false}
    ]},
    {"frame": 2, "phase": "after", "objects": [
      {"id": 1, "bbox": [104, 80, 144, 120], "visible": true}
    ]}
  ]
}
```

对自录视频逐帧记录球框与跨帧不变的真实 ID；可按 `data/demo/gt.json` 的格式编辑。`visible=false` 只用于完全遮挡；部分遮挡而仍可辨认时应事先统一框标注规则并保留可见样本。没有球的标注帧使用 `objects: []`。阶段名可自定；建议固定遮挡前、遮挡中、遮挡后三个窗口。比较 ID 连续性时建议完整逐帧标注，稀疏标注无法评价未标注区间的切换。

从现成标注工具导出时需转换为本格式，保证坐标没有被按显示尺寸缩放。不要从预测框直接复制“真值”。课程项目建议两人交叉复核 10%–20% 的帧。

## 本次云端结果（功能验证，单次测量）

环境：Linux x86_64，Intel Xeon Platinum 8573C，容器可见 3 个逻辑 CPU；PyTorch CPU 2.7.1、Ultralytics 8.3.228、OpenCV 4.11.0，4 个 torch 线程。共享云资源且有其他验证任务并行，FPS 不用于推断 Python 版本性能差异。没有运行 GPU、Windows 桌面或摄像头。

YOLO11n，imgsz=640，conf=0.1，buffer=30；90 帧照片平移视频，球完全遮挡 8 帧，可见真值实例 82 个。Python 3.11 与 3.12 均完成整个输入→检测跟踪→MP4→CSV→评估链路。

| 项目 | Python 3.12.14 | Python 3.11.17 |
|---|---:|---:|
| 自动化测试 | 9 通过 | 9 通过 |
| 处理视频帧数 | 90 | 90 |
| TP / FP / FN | 82 / 41 / 0 | 82 / 41 / 0 |
| 可见实例召回率 | 100% | 100% |
| 精确率 | 66.67% | 66.67% |
| ID 切换 | 1 | 1 |
| 稳定性代理值 | 98.78% | 98.78% |
| 遮挡后同 ID 恢复 | 1/1 | 1/1 |
| 含写视频的处理 FPS（不去预热） | 3.02 | 2.41 |

不能将这一个照片生成的样本推断为真实运动下的 100% 召回率：预训练可能包含原图，背景误检较多，且平移远比快速球体运动简单。唯一预测 ID 共 3 个，也不代表有 3 个真实球。

Python 3.12 的阶段对比（FPS 去前 5 帧预热）：

| 阶段 | TP / FP / FN | 召回率 | 精确率 | ID 切换 | FPS |
|---|---|---:|---:|---:|---:|
| before：帧 0–34 | 35 / 12 / 0 | 100% | 74.47% | 1 | 3.60 |
| occluded：帧 35–42 | 0 / 1 / 0 | 不适用 | 0% | 0 | 4.24 |
| after：帧 43–89 | 47 / 28 / 0 | 100% | 62.67% | 0 | 2.61 |

遮挡期间所有球均不可见，因此这一阶段召回率无定义。重现后没有新的 ID 切换，但背景误检仍存在。

另测 imgsz=320：去预热处理 FPS 为 8.09，但可见球召回率 **0%**，没有有效跟踪。该运行未保存视频，且资源负载不同，只作为参数取舍的功能示例；它证明降低分辨率不能只看速度。本例默认仍保留 640。原始输出见 `evidence/benchmark320/`。

## 确定性双目标遮挡对照

两个球沿不同高度做匀速运动，共 120 帧，其中球 1 在帧 45–52 完全不提供检测，球 2 全程提供检测。将这些框传入同一 Ultralytics `BYTETracker` 实现，检测分数固定为 0.9。主程序仍使用 `model.track`；直接调用内部类只用于隔离跟踪行为的测试。

| track_buffer | TP / FN | ID 切换 | 重现后同 ID 恢复 |
|---|---|---:|---:|
| 30 | 232 / 0 | 0 | 1/1 |
| 2 | 231 / 1 | 1 | 0/1 |

这说明 lost 缓存对短遮挡有作用；不说明所有高速运动或多球交叉都能恢复。该结果的召回率来自注入框后的跟踪输出，不能当成 YOLO 检测召回率。

## 论文正式实验建议与一键重复

1. 保留独立原始视频与逐帧真值，固定设备、分辨率、线程数、置信度和视频保存开关。
2. 采集单球/双球、慢速/快速、无遮挡/短遮挡/长遮挡多组自然运动。每组至少多段视频，记录拍摄条件和可见球尺寸。
3. 先比较 imgsz=320/640，再在同一检测参数下比较 buffer=2/30；其他参数保持一致。
4. 同一设置重复 3 次以上，汇报 FPS 均值和标准差，准确率按所有视频累加 TP/FP/FN 后计算，避免小样本和大样本等权误导。
5. 将所有模型/输入文件 SHA256、依赖版本、硬件与参数和原始 CSV 归档。`summary.json` 已保存权重散列；输入可以在 PowerShell 用 `Get-FileHash data/demo/input.mp4 -Algorithm SHA256` 记录。

```bat
python -m tools.benchmark --video data/demo/input.mp4 --gt data/demo/gt.json --output runs/repeated --repeats 3 --imgsz 320 640 --buffers 2 30
```

该工具重新加载每次运行的模型，保留每次的 summary、tracks、frames、evaluation，并生成 `comparison.csv`。默认无显示、不写视频，避免显示刷新和编码干扰。CPU 下可能需要数分钟。新实验目录必须不存在。单次 smoke 结果中的标准差 0 只是 repeats=1 的占位值，不能解释为没有测量波动。
