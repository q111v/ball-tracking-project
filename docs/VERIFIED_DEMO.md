# 可直接复现的近景球体跟踪演示

## 使用方式

在按 README 安装依赖后，从项目根目录执行：

```bat
python run_verified_demo.py
```

或双击 `run_demo.cmd`（需要项目 `.conda-env` 环境，或当前 PATH 中有已装依赖的 Python）。首次配置可在 Anaconda Prompt 运行 `windows\setup_and_test.cmd`。

该入口自动选择 `data/verified/ball_demo.mp4`、公开 COCO 预训练 `yolov8s.pt`、内置 ByteTrack、`--color-assist`，并保存视频。输出目录带时间戳，避免覆盖。窗口中紫红色线为本项目产生的观察轨迹，框旁显示 ID 和置信度。按 Q 退出；提前退出的片段可能不满足完整演示验收条件。

无窗口复现：

```bat
python run_verified_demo.py --no-display
```

运行完会自动审计实际生成的 `tracks.csv`，输出 PASS 或 FAIL。审计条件：至少90帧、唯一有效ID恰为1、至少90%的帧有ID、最长缺失不超过8帧、实际观察中心累计位移至少200像素。这是输出连续性的检查，不是检测召回率或对任意新视频的效果保证。

## 输入的来源与范围

真实、未预标注的近景持球视频：https://github.com/jonathanfoster/ball-tracking 。本次只使用其中视频素材，不使用该仓库的颜色跟踪代码或依赖。

推荐输入是原视频零基第45–164帧，共120帧，30 FPS，4秒。画面内容保持连续顺序，没有降速、合成运动或预先绘制预测轨迹。由于原始视频很长且存在出画、遮挡等复杂情况，推荐片段不能代表整段视频的通过率。固定来源提交、输入散列与裁剪范围见 `data/verified/SOURCE.json`。第三方素材保留原有权利。

## 本次改动与方法

默认模型从 YOLO11n 改为 YOLOv8s：后者在此近景球体上检出效果更好，但 CPU 计算量更大。原来的 `--model yolo11n.pt` 仍可使用。两者均为公开 COCO 预训练权重，不从零训练。

只更换视频和权重仍有间歇漏检，因此新增可选 `--color-assist`：

1. YOLO 首先以 sports ball 类和足够置信度确认目标；未确认前，辅助模块不产生框。
2. 从确认框中心区域学习高饱和颜色的 hue 模态，不硬编码成“绿色球”。
3. 在上一观察框附近进行颜色分割；候选必须满足颜色、面积、形状与空间范围限制。
4. YOLO 漏检但可见像素支持目标位置时，补充低分观察框；通过 Ultralytics 的 postprocess 回调先插入观察，再由其**内置 ByteTrack**统一关联 ID。
5. 若像素不支持目标，不沿速度外推或伪造检测；连续辅助失败超过12帧后清除颜色状态。

因此这是 **YOLO 初始化 + 可选颜色观测辅助 + ByteTrack** 的混合方案。不能把辅助帧计为纯 YOLO 检测成功，低分观察也不能单独建立新ID。`summary.json` 的 `color_assist_inserted_observations` 明确记录补充框数量。

适用范围：单个颜色鲜明、与背景有明显差异、移动幅度适中的近景球。相似颜色背景、多个相同颜色球、剧烈光照变化、长遮挡、远景网球仍可能失败。通用多目标流程默认不启用颜色辅助；命令行 `main.py` 需显式指定，推荐演示入口明确启用。

## 结果记录

本次实测指标以 `evidence/verified-demo/track_audit.json`、`summary.json` 为准；处理视频为同目录 `annotated.mp4`。输入没有轨迹或目标框，输出紫红轨迹来自本次运行的检测/辅助观察。

历史远景网球失败记录仍保留在 `docs/ONLINE_VIDEO_TEST.md`，不能将新的近景片段结果写成远景网球已修复。课程论文正式实验应另外采集视频并制作独立真值，分别比较“纯YOLO+ByteTrack”与“颜色辅助”设置。

本次明确采用经过筛选的短片段作为可运行演示，不保证原始37.9秒全片都能稳定跟踪。此前测试的6秒版本有多个ID，未通过连续性审计，原始输出保存在 `evidence/extended-demo-failed/`，不将其包装为成功结果。

## 最终120帧复跑结果

- 输入：120帧、30 FPS、1152×640、原速连续4秒。
- 有有效ID的帧：120/120（输出覆盖率100%，不是纯YOLO召回率）。
- 唯一有效ID：1；最长缺失：0帧。
- 观察中心累计轨迹长度：2066.26像素。
- 颜色辅助插入观察框：46个；辅助分数固定为0.22，不是神经网络概率。
- 本次云端CPU处理吞吐率：3.16 FPS；视频按原始30 FPS保存。功能验证通过，不声称CPU实时30 FPS。
- Python 3.11、3.12 各通过11项自动化测试，含无YOLO种子不输出颜色框、球不存在时不伪造检测、辅助失效重置等。
- 处理视频重新解码检查必须为120帧；抽看第0、40、80、119帧，球框和ID跟随球体，紫红线确为本项目生成。预览见 `evidence/verified-demo/preview.jpg`。

Python 3.11 也另行完整复跑最终120帧，连续性审计PASS、保存视频重新解码120帧；对应summary、CSV和审计报告见 `evidence/verified-demo-python311/`。
